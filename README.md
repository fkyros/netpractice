# NetPractice

## Description
This projects consists in 10 exercises design to train basic abilities regarding networking. Here you learn about IP addressing, subneting, routing, gateways and routing tables.

## Instructions
All 10 exercises are obtained via the net\_practice platform, you can type on your computer the command `run.sh` to execute it.

## Resources
- TCP/IP addressing
- Subnet masks
- Default gateways
- Routers, Switches
- OSI Layers
