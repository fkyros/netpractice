# NetPractice

## Description
This project teaches you the basics of networking. It's made of 10 exercises design to train basic abilities regarding IP addressing, subneting, devices, gateways and routing tables.

## Instructions
All 10 exercises are obtained via the net\_practice platform, clicking on the button "Get my config" once you solve it. This platform can be launch accessing the net\_practice folder and running the command `run.sh` to execute it.

To submit the exercise, you must complete the 10 exercises and place the exported solutions inside the root of your repo.
